SATSUMA PRONTO - My Summer Car mod
==================================

One button that builds the stock Satsuma into your save.
Money, items and progress stay the same.

The car comes with: all stock parts bolted, charged battery, spark plugs,
oil filter, alternator belt, rear seat, full fuel tank, new tires and the
spare wheel next to you.

The mod text follows your Windows language (15 languages, English fallback).

INSTALL
1. Install MSCLoader:
   https://www.nexusmods.com/mysummercar/mods/147
2. Copy SatsumaPronto.dll into the game's "Mods" folder
   (e.g. ...\steamapps\common\My Summer Car\Mods).

USE
1. Start the game and stay in the MAIN MENU.
2. Mod settings > Satsuma Pronto > "Build the Satsuma in my save".
3. Confirm and click CONTINUE.

The mod makes a backup first, inside the save folder:
%USERPROFILE%\AppData\LocalLow\Amistech\My Summer Car\backup_<date>
To undo, copy the backup files back into that folder.

Tip: on the first drive, pull the choke to start the engine.
